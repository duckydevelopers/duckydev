02 / THE RUN GUIDE

From error message
to first fix.

You’ll need an internet connection and a Windows administrator account. Save your work and close the affected app first.

Read the full script before running ↗
  1. 1

    Open PowerShell as administrator

    Open Start and search for Windows PowerShell. Right-click it, choose Run as administrator, and approve the Windows prompt. On a 64-bit PC, use the regular version, not “Windows PowerShell (x86)”. PowerShell 7 works too.

    Use PowerShell, not Command Prompt. ARM-based Windows devices aren’t supported by this version.

  2. 2

    Paste this command. Press Enter.

    The command retrieves the script from this site and runs it in your PowerShell window.

    POWERSHELL · ADMINISTRATOR
    irm 'https://duckydevelopers.github.io/duckydev/duckyfixer.txt' | iex

    Only run scripts from a source you trust. You can inspect the script using the link above.

    Prefer the iwr command?

    This version explicitly passes the response text into iex:

    iwr -UseBasicParsing 'https://duckydevelopers.github.io/duckydev/duckyfixer.txt' | Select-Object -ExpandProperty Content | iex
  3. 3

    Pick the error you’re seeing

    Type a menu number and press Enter. Choose 1 for both runtime fixes, 2 for DirectX, or 3 for Visual C++. Options 4 and 5 show help and return to the menu. Type 0 to quit.

  4. 4

    Review and approve each fix

    Type y to start the session. Then review each fix’s explanation and type y only for the fixes you want. Press Enter or type n to skip a fix. Declining the initial session prompt stops the whole run.

    If an optional troubleshooter is configured, you’ll see its URL and get a separate prompt. Close that program when it finishes so the runtime fixes can continue. With no troubleshooter configured, this step is skipped.

  5. 5

    Let it finish, then try your app

    Keep PowerShell open while it downloads and runs the selected installers. After a DirectX installation, save your work and restart Windows before trying again. Follow any other restart notice shown in the log. Ducky won’t reboot for you.

    When the session finishes, review the completed or skipped steps. You can then close PowerShell. If a step fails, the run stops and earlier installations remain in place.

03 / IF YOU GET STUCK

A little help
along the way.

“Run as administrator” or “Access denied”

Close the current PowerShell window and open a new one using Run as administrator. If your account can’t approve the prompt, ask the PC administrator. Then run the command again.

A download or verification failed

Check your internet connection and read the error in the log. A signature or checksum failure stops the file from running. Don’t override it; report the filename and error to the tool publisher. If an installer is still running elsewhere, let it finish before retrying.

Defender or Smart App Control blocked a file

Keep protection enabled. Note the detection name and blocked filename, then contact that file’s publisher for an updated release or a review of the detection. Menu options 4 and 5 provide guidance; they don’t turn security features off.

Where are the logs?

Open File Explorer, paste the path below into its address bar, and press Enter. Open the newest log for the consent choices, installer exit codes, and any error.

%LOCALAPPDATA%\DuckyFixer\Logs
The app still reports the same error

Restart if the installer requested it, then try again. If the error persists, repair or reinstall the affected app using its official installer and contact its publisher with the exact error and Ducky log. Don’t download individual DLLs from unfamiliar sites.

What does this actually change?

The selected fixes install Microsoft runtime components. The DirectX package adds legacy libraries; it doesn’t upgrade Windows’ built-in DirectX version. The Visual C++ option includes older, unsupported generations. DirectX runtime components cannot be uninstalled, and completed installations aren’t automatically rolled back.

Ducky leaves Defender, Core isolation, Smart App Control, and the vulnerable-driver blocklist enabled. Consent lets you choose what runs; it is not a guarantee that a fix will work.
